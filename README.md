# Online Examination System

A modern, responsive web application built with **Django** and **Bootstrap 5** for conducting online examinations with instant automated grading and score calculation.

---

## 🚀 Features

- **Exam Portal**: View all available exams with total marks and passing criteria.
- **Interactive Test Interface**: Multiple Choice Questions (MCQs) powered by clean radio-card UI components.
- **Automated Evaluation**: Real-time score calculation and pass/fail determination upon submission.
- **Exam Creation Form**: Dedicated frontend form for instructors to create new examinations.
- **Django Admin Integration**: Inline question manager for adding, editing, and deleting questions effortlessly.
- **Responsive Design**: Built using Bootstrap 5 CDN and Bootstrap Icons for mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Backend**: Python, Django
- **Frontend**: HTML5, CSS
- **Database**: SQLite3 (default Django DB)
- **Version Control**: Git & GitHub
